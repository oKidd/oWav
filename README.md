# oWav

**oWav** es un programa sumamente sencillo, rápido y limpio para descargar música de YouTube en formato WAV.

Solo pegas el enlace, haces clic en **Descargar WAV**, eliges la carpeta de destino y listo. Sin cuentas, sin historial y con un flujo directo.

## Cómo usarlo

### 1. Abre oWav

Al iniciar el programa encontrarás una interfaz limpia y lista para recibir un enlace de YouTube.

![oWav al iniciar](https://i.imgur.com/1F2NN2h.png)

### 2. Pega el enlace

Pega el enlace del video de YouTube en el campo indicado. Cuando el video sea reconocido, haz clic en **Descargar WAV**.

![Enlace de YouTube pegado](https://i.imgur.com/JxOopDL.png)

### 3. Elige la carpeta y espera la descarga

Antes de comenzar, selecciona la ruta donde quieres guardar el archivo. Después, oWav empezará a preparar y descargar el audio en formato WAV.

![Descarga en progreso](https://i.imgur.com/vIKC0Uy.png)

### 4. Archivo listo

Cuando termine la descarga, el programa te avisará que tu archivo está listo. Desde el mismo aviso puedes hacer clic en **Abrir carpeta** para ir directamente a la ubicación elegida.

![Descarga completada](https://i.imgur.com/W7sAjcB.png)

## Características

- Interfaz simple, rápida y limpia.
- Conversión a formato WAV.
- Selección de la carpeta de destino.
- Acceso directo a la carpeta después de descargar.
- Procesamiento local, sin cuentas y sin historial.

## Desarrollo

Instala las dependencias y ejecuta el proyecto en modo desarrollo:

```bash
npm install
npm run dev
```

Para generar una versión distribuible:

```bash
npm run dist
```

## Uso responsable

Utiliza oWav únicamente con contenido que tengas derecho a descargar y convertir. Respeta los derechos de autor y los términos de servicio de YouTube.
